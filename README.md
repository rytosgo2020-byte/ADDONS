# Cyberpunk Cyberware — Garry's Mod (v2.1)

Аддон киберимплантов в стиле Cyberpunk 2077: 7 систем организма, 78 имплантов МК.1–МК.5, кибердека с ОЗУ и 14 скриптами, человечность, киберпсихоз и Чёрный заслон.

Установка: распакуйте папку `cyberpunk_cyberware` в `garrysmod/addons/`. Ставьте только одну языковую версию: русскую или английскую.

## Управление (по умолчанию, меняется в F8 → «Настройки»)

| Клавиша | Действие |
|---|---|
| F8 | Личное меню: схема тела, характеристики, скрипты, настройки |
| F6 / `/ripperdoc` | Терминал риппердока (только админы) |
| Z | Сандевистан / Берсерк (повторное нажатие отключает Сандевистан досрочно) |
| X | Кибердека: меню быстрого взлома (1–9 — выбор скрипта, X / ПКМ / Esc — закрыть) |
| V | Рывок Керензикова |
| F | Сканирование оптикой Кироши |
| G | Ракетная система рук |
| B | Оптический камуфляж |

Чат: `/implants` — открыть личное меню.

## Человечность и киберпсихоз

- Нагрузка: МК.1 — 4, МК.2 — 6, МК.3 — 8, МК.4 — 11, МК.5 — 14 (оптика 4–10, ОС 10–22). Лимит по умолчанию — 100.
- Стадии: ниже 50 — нестабильность, ниже 25 — киберпсихоз, ниже 0 — терминальная стадия. Примерно: 6 имплантов МК.3 — нестабильность, 8 — киберпсихоз, полный комплект МК.3 — терминальная стадия.
- Границы видны сразу: метки порогов и подсказка «до порога: N» в HUD, крупный баннер при пересечении порога, прогноз человечности в терминале риппердока.
- Эффекты нарастают по стадиям (камера не трясётся):
  - нестабильность — навязчивые мысли-субтитры, шёпот, красная виньетка;
  - киберпсихоз — галлюцинации-фантомы, фантомные звуки за спиной, окружающие на миг подсвечиваются как враги; +10% урона, но разброс ×1.25;
  - терминальная стадия — провалы сознания и приступы ярости (+30% ближнего боя, +15% скорости, −10% входящего урона на 8 с). Игроки рядом получают сообщение и видят красный контур — это РП-сигнал, что человек на грани. Оптика Кироши помечает киберпсихов.

## Чёрный заслон

- Скрипты «Шёпот из-за Заслона» и «Прорыв Чёрного заслона» выдаёт риппердок. Они очень сильные, но дают **порчу** (0–100).
- Каждая единица порчи отнимает 0.5 человечности. Через 20 с после последнего прорыва порча начинает спадать.
- На 100 единицах наступает перегрузка: урон, ЭМИ на 5 с, порча сбрасывается до 60.
- Кибердека «Шлюз Чёрного заслона» МК.5 вдвое снижает получаемую порчу и усиливает «Прорыв».
- Риппердок может очистить порчу кнопкой «Очистить заслон».

## Консольные переменные клиента

- `cyber_hud 0/1` — HUD имплантов
- `cyber_psycho_fx 0..1` — интенсивность визуальных эффектов психоза
- `cyber_ghosts 0/1` — шлейф Сандевистана
- `cyber_ui_sounds 0/1` — звуки интерфейса
- `cyber_key_<действие>` — коды клавиш (удобнее менять в меню)

## Баланс

- Потолки суммарных бонусов (`CYBERWARE.Config.Caps`): +200 HP, 50% снижения урона, 30% уклонения, +35% скорости, +150% ближнего боя, +50% огнестрела, 6 HP регенерации, 25% вампиризма.
- Регенерация работает только вне боя (через 4 с после получения урона).
- Скрипты кибердеки расходуют ОЗУ и имеют собственную перезарядку.

Все параметры (пороги, последствия психоза, Чёрный заслон) — в `lua/autorun/cyberware_config.lua`. ID имплантов не менялись, прежние сохранения (SQLite) загружаются.
